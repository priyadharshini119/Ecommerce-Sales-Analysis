Ecommerce-Sales-Analysis

Project Overview

This project focuses on analyzing online retail sales data using Python, Pandas, and SQL to understand sales performance and customer purchasing patterns.

Objectives

- Clean and preprocess the dataset.
- Remove duplicate records.
- Analyze sales and revenue.
- Identify top-performing countries.
- Analyze customer purchasing behavior.
- Understand monthly revenue trends.

Technologies Used

- Python
- Pandas
- SQL
- SQLite
- Matplotlib
- Seaborn
- Jupyter Notebook

Project Structure
Ecommerce-Sales-Analysis
├── data/
├── notebooks/
├── app.py
├── requirements.txt
└── README.md

Project Tasks

1. Data Cleaning and Preprocessing
2. SQL-Based Data Analysis
3. Sales and Revenue Analysis
4. Data Visualization

Key Analysis

- Total revenue analysis
- Top countries by sales
- Monthly revenue trends
- Customer purchasing behavior
- Average basket size
- Sales patterns by time

Installation

Install the required libraries:

pip install -r requirements.txt

How to Run

1. Download the project repository.
2. Install the required Python libraries.
3. Open Jupyter Notebook.
4. Run the notebooks in the correct order.

Conclusion

This project demonstrates practical skills in data cleaning, SQL analysis, data manipulation, and visualization to derive meaningful insights from online retail data.
